# Tablero SATHIRI y SATMEC

App interna para llevar obras, tareas, avances y la bitácora diaria de los residentes de SATHIRI y SATMEC.

- Cada persona entra con su PIN.
- Los datos se guardan en una hoja de Google del gerente, a través de Apps Script.
- La gerencia ve todo; cada persona ve sus tareas y sus obras.
